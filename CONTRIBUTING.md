# Contributing

Issues and pull requests are welcome. Keep changes small, include an offline test
(`npm test`), and keep zero runtime dependencies. By submitting a contribution you agree
it is licensed under Apache-2.0 (LICENSE, section 5).

If you operate one of the mirrors or work on NOAA data dissemination and would like the
tool to read the mirrors differently (request rate, access pattern), please open an issue.

Security issues: report privately to support@embryospace.com.
